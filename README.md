# Definition of Done (DOD)
1. Code Implemented
2. Code Reviewed
3. Unit Tests Passed
4. Code Integrated
5. Integration Tests Passed

# Sprint Goal
Allow users to start on a home screen, browse restaurants, view menu items, add items to order, and remove items from order

# Sprint Engineering Tasks
## PBI 1: Create Home Screen
- Design Home Screen
- Implement Home Screen
- Implement functionality to transition to the restaurant display
- Test Home Screen
- Test Home Screen transition functionality
## PBI 2: Create Restaurant Displays
- Design Restaurant Display Page
- Design Individual Restaurant Displays
- Implement Restaurant Display Page
- Implement Individual Restaurant Display
- Implement functionality to transition to a restaurant's menu
- Add Restaurant Display Data
- Test Restaurant Display Page
- Test Individual Restaurant Displays
- Test Restaurant Display transition funcitonality
## PBI 3: Create Viewable Menus with Items
- Design viewable menu
- Implement Viewable Menu
- Implement Menu Items
- Implement functionality to select a menu item
- Add Menu Item Data
- Test Viewable Menu
- Test Menu Items
- Test Menu Item Selection functionality
## PBI 4: Allow Users to Add Items to Order
- Implement Order data storage
- Implement functionality to add items to order
- Test Add Item functionality
## PBI 5: Allow Users to Remove Items from Order
- Design Order view
- Implement functionality to view the order
- Implement functionality to remove items from order
- Test View Order functionality
- Test Remove Items functionality
## Integration
- Combine the branches
- Connect transitions and resolve placeholders
- Repeat all previous tests in the integrated system
